# Antigravity HUD

A lightweight Windows tool to track your Google Antigravity (`agy`) quota in real time from your system tray or a compact floating desktop bar.

## What it does

- **Floating HUD**: A slim horizontal bar docked at the top of your screen so you can glance at quotas while coding. Right-click to choose which models to show.
- **Dashboard**: A flyout window showing full model breakdowns, remaining percentages, and reset countdowns.
- **System Tray**: Sits in the notification area, changes icon color when quotas run low, and shows a quick summary on hover.

## Requirements & Usage

- Requires the `agy` CLI to be installed and available in your `PATH`.
- Download `AntigravityHUD.exe` from [Releases](https://github.com/gtwndtl/agy-usage-tray/releases) and double-click to run. It is a standalone single-file binary with zero extra dependencies.
